# Nuestro primer mes

Vídeo vertical (1080×1920, 26,7 s, con música) para celebrar el primer mes juntos.

- `aniversario-primer-mes-whatsapp.mp4`: listo para enviar.
- `aniversario.html`: ábrelo en el navegador para verlo y escucharlo con controles.

## Personalizar

1. Edita el bloque `CONFIG` al principio de `src.html` (nombre, días, firma, fecha).
2. `python3 build.py` (mete las fuentes dentro del HTML).
3. `node render.mjs aniversario.html aniversario-primer-mes.mp4 60 4 4` (necesita Playwright y ffmpeg).
